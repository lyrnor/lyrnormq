# Frozen phase2a contract — supersedes Phase1 QoS boundaries
Scope: MQTT3.1.1 clean-session live QoS0/1/2. No persistent-session/reconnect/crash durability claims. Retain/Will/credentials and MQTT5 remain unsupported. Preserve existing tested code except required extensions.

## Protocol
Publish becomes `Publish { topic:String, payload:Vec<u8>, qos:u8, packet_id:Option<u16>, dup:bool, retain:bool }`. qos0 requires None and dup=false, qos1/2 requires nonzero Some. retain=true still UnsupportedFeature. Add `PubAck {packet_id:u16}`, `PubRec {packet_id:u16}`, `PubRel {packet_id:u16}`, `PubComp {packet_id:u16}`. PUBREL flags fixed 0x2 including repeats (no DUP bit). Remaining APIs unchanged. Fix production codec tests/fixtures in owned crate. Avoid encode->decode payload-copy validation by shared validation helpers if safely feasible, retaining identical malformed checks.

## Router
Keep `subscribe(client,filter)` as QoS0 wrapper and `matching_clients(topic)` as dedup IDs wrapper. Add `subscribe_qos(&mut self,client:u64,filter:String,qos:u8)->bool` (0..2 only, replacement updates grant), `matching_qos(&self,topic:&str)->Vec<(u64,u8)>` unique client, max matching subscription QoS. Keep other APIs. Indexed matching and cleanup must not add unbounded stale metadata.

## Session
Preserve PacketIdentifiers and IncomingQos2, integrate rather than rewrite. Extend SessionError with InvalidQos and UnexpectedAck.
Add `pub enum AckKind { PubAck, PubRec, PubComp }` and `pub enum AckAction { Complete, SendPubRel, Ignore }`, derive Debug/Clone/Copy/PartialEq/Eq.
`pub struct OutgoingQos`; `new(max_inflight:usize,max_message_size:usize)->Self`; `start(&mut self,qos:u8,message:Vec<u8>)->Result<NonZeroU16,SessionError>` QoS1/2 only and bound encoded message bytes; `ack(&mut self,id:NonZeroU16,kind:AckKind)->Result<AckAction,SessionError>`; `inflight_count(&self)->usize`; `is_full(&self)->bool`. QoS1 waits PubAck then frees ID; QoS2 waits PubRec -> SendPubRel (release stored payload) -> waits PubComp -> frees ID. Duplicate PubRec while waiting PubComp -> SendPubRel. Unknown ACK -> Ignore. Wrong-stage ACK -> UnexpectedAck and state unchanged. No timer retry within connection; eventual persistent reconnect retransmits per MQTT3.1.1 section4.4, not implemented in clean sessions. Public API docs and tests cover IDs not reused before final ACK, duplicate/control packets and bounds.

## Transport
Depends mqtt-session in addition existing dependencies. BrokerConfig adds `max_inflight:usize` default32, valid1..65535; existing limits retained. Route outgoing QoS=min(incoming QoS,max matching granted subscription QoS). SUBACK grants requested QoS0/1/2. Incoming QoS1 route then PubAck; incoming QoS2 use existing IncomingQos2 storing protocol-encoded publish bytes then PubRec, only route delivery on PubRel, return PubComp for duplicates/unknown PubRel without redelivery. Inbound/outbound ID namespaces independent. Outgoing assign unique packet IDs through OutgoingQos, await correct acknowledgements; duplicate PubRec returns PubRel, never redeliver QoS2 PUBLISH after PubRec. Stop draining outgoing channel when inflight full but keep reading ACKs (bounded queue; slow clients disconnected on queue overflow). Do not acknowledge packets rejected by resource limits. All current timeout, shutdown, takeover and generation safety invariants remain. Tests must verify direction-specific ACK transitions, QoS downgrade, window release and independent IDs. Tests/fixtures in transport updated for new protocol fields.

## Storage (parallel independent groundwork)
Do not implement SQLite or integrate runtime disk IO this round. Extend existing bounded memory storage with atomic multi-record transaction API. Add public `Mutation { Put(StorageKey,Vec<u8>), Remove(StorageKey) }`, `MemoryStorage::apply_batch(&mut self, mutations:Vec<Mutation>)->Result<(),StorageError>`. Bound batch operation count and total incoming value bytes against existing limits before staging to prevent unbounded transient cloning; define max operations via max_entries and max bytes via max_bytes. Clone/stage existing bounded records and commit only after every operation succeeds. Final/intermediate capacity policy must be documented. Empty batch succeeds. Add rollback, namespaces, replacement accounting tests. This is volatile atomicity only; SQLite WAL durable backend requires transaction/outbox schema and restart fault tests in phase2b.
