# lyrnormq Dashboard 页面设计

浅色运维后台交互原型。所有连接、消息、吞吐、资源和事件数据均为本地合成样例，尚未连接 Broker，也不代表实测性能。无需安装前端依赖，不修改 Rust 服务。

## 预览

直接打开 `dist/index.html`，或在仓库根目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory dashboard/design/dist
```

浏览器访问 `http://127.0.0.1:8766/`。所有资源在本地，无外部字体、脚本或接口请求。

## 页面与交互

| 页面 | 内容 |
| --- | --- |
| 运行概览 | 连接、会话、入出站消息速率，趋势图，资源和安全状态，最近连接 |
| 连接与会话 | 在线/离线筛选、Client ID/用户/IP 搜索、协议版本过滤、分页与详情抽屉 |
| 主题与消息 | 活跃 Topic、订阅过滤器、保留消息及合成 Payload 预览 |
| 认证与授权 | 本地用户、Topic 权限、认证准入限制、mTLS 证书策略与启动参数样例 |
| 连接入口 | TCP/TLS/WS/WSS 配置选项；样例仅选择 WSS，不表示多监听共享状态已实现 |
| 实例配置 | 启动配置只读展示 |
| 事件记录 | 按级别过滤的演示事件 |
| 规则引擎 | 明确标记规划中，仅展示未来 SQL 交互方向 |

全局搜索支持连接与主题，快捷键为 Cmd/Ctrl+K。详情抽屉支持 Escape 关闭、焦点约束及关闭后焦点恢复。手机端收起左侧导航，宽表在容器内横向滚动。

## 与现有能力的边界

- 页面围绕现有持久会话、SQLite、认证/ACL、rustls 和 mTLS 设计。
- 管理 API、实时指标、事件查询、配置修改及控制台登录尚需实现。页面中的用户头像不表示管理端鉴权已存在。
- 本地 JSON 策略与 Argon2id 示例只用于说明；密码哈希是占位符，不能直接部署。
- Redis/PostgreSQL 认证、规则执行、证书热加载不在本次实现范围内。
- 后续接入应先冻结管理 API、指标单位、采样窗口、分页和访问控制契约；避免在 Broker 消息处理热路径增加同步统计或全量扫描。

## 验证

- `node --check dashboard/design/dist/app.js`：通过。
- `git diff --check`：通过。
- 实际浏览器验证：1440×1024 桌面和 390×844 手机布局；两种布局页面无横向溢出。
- 已验证连接组合搜索/状态/协议过滤、空结果、详情，MQTT 3.1.1 会话文案、全局 Topic 搜索及消息抽屉、证书策略、手机菜单切换；浏览器未捕获 JS error/warn。
- 静态原型未改动 Rust，因此本轮未重复运行 Cargo 编译或协议测试。
