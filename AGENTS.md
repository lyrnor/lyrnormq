# Engineering rules
Use Rust stable, edition 2024. Production code: no unsafe, unwrap or expect; typed errors, bounded resources, no blocking IO in async tasks, no locks across await. Run cargo fmt, clippy --all-targets -- -D warnings, and tests. Respect docs/contracts/phase1.md and superseding docs/contracts/phase2a.md and docs/contracts/phase2b.md and docs/contracts/phase2c.md and docs/contracts/phase2d.md and docs/contracts/phase2e.md and docs/contracts/phase2f.md and docs/contracts/phase2g.md and docs/contracts/phase2h.md and docs/contracts/phase2i.md and docs/contracts/phase2j.md and docs/contracts/phase2k.md and docs/contracts/phase2l.md and docs/contracts/phase2m.md and docs/contracts/phase2n.md; propose interface changes to coordinator first. Each agent writes only its owned paths in an explicitly assigned independent Git worktree and branch, commits tested changes, reports hash and limitations. Do not edit shared root Cargo.toml or other modules. Regression tests precede bug fixes. Never claim unimplemented MQTT compatibility.
Ownership: protocol crates/mqtt-protocol; transport crates/mqtt-transport; router crates/mqtt-router; session crates/mqtt-session; storage crates/mqtt-storage; quality tests, benches, fuzz, .github/workflows. Auth specialist owns crates/mqtt-auth. Coordinator owns bin/rmqtt, workspace and docs.

Structure: lib.rs contains crate documentation, module declarations and public re-exports only. Put data types, business functions, impl blocks and test bodies in responsibility-specific modules. Preserve existing public import paths and durable schema during structural refactors.
