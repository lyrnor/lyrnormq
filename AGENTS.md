# Engineering rules
Use Rust stable, edition 2024. Production code: no unsafe, unwrap or expect; typed errors, bounded resources, no blocking IO in async tasks, no locks across await. Run cargo fmt, clippy --all-targets -- -D warnings, and tests. Respect docs/contracts/phase1.md; propose interface changes to coordinator first. Each agent writes only its owned paths in an explicitly assigned independent Git worktree and branch, commits tested changes, reports hash and limitations. Do not edit shared root Cargo.toml or other modules. Regression tests precede bug fixes. Never claim unimplemented MQTT compatibility.
Ownership: protocol crates/mqtt-protocol; transport crates/mqtt-transport; router crates/mqtt-router; session crates/mqtt-session; storage crates/mqtt-storage; quality tests, benches, fuzz, .github/workflows. Coordinator owns bin/rmqtt, workspace and docs.
